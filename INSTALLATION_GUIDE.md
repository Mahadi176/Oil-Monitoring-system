# Installation and VS Code guide
1. Extract the ZIP and open the `oil_monitor_project` folder in VS Code.
2. Install Python 3.11 or 3.12.
3. In the VS Code terminal, create and activate a virtual environment using the commands in README.md.
4. Install dependencies with `pip install -r requirements.txt`.
5. Run `python -m pytest -q`.
6. Start the dashboard with `streamlit run app.py`.
7. Register a username and five-digit PIN, then upload one `.xlsx` file per organisation from the sidebar.
